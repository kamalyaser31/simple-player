What's New in Version 1.1

This version introduces a major set of new features focused on streaming, recording, and professional workflows.

Key Features:

  • YouTube Integration: Open, search, and download YouTube videos and playlists directly within the app.
  • Recording: Capture audio from your default input device and save it to your recordings folder.
  • Bookmarks: Create named bookmarks to easily return to specific positions in your audio files.
  • Favorite Videos: Manage a central list of your favorite YouTube links and other stream URLs for quick access.
  • Silence Removal: Automatically skip silent passages in audio with a configurable filter.
  • Global Shortcuts: Control key functions like play/pause, seek, volume, and recording from anywhere in Windows.
  • A-B Loop: Repeat a specific segment of an audio file continuously.
  • Enhanced Playback Controls: Enjoy precise control with variable speed playback and multiple seek step options.

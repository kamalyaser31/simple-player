Simple Audio Player User Guide

Last updated: November 13, 2026. Version 2.0.0.

This guide is for people who use Simple Audio Player with a screen reader such as NVDA. It starts with the tasks you do every day, then lists every setting and every shortcut. Menu names, button names and messages are written the way the English version of the app shows or speaks them.

Overview

Simple Audio Player is a media player for Windows. You control it with the keyboard. It speaks its own messages through your screen reader, for example the new volume or the name of a bookmark.

You can use it to:

  • play audio files, a whole folder, or a web stream link;
  • search YouTube, open YouTube links, and play them as audio;
  • follow YouTube channels and playlists without a Google account;
  • keep bookmarks inside long files and repeat a part of a file;
  • record from your default input device, for example a microphone;
  • control playback from any program with global shortcuts.

The app keeps your data in separate files, so you can back up or reset one kind of data without touching the others. See Data, Backup and Restore.

System Requirements

  • Windows. The app is Windows only.
  • A working sound output device.
  • For recording: a working input device, such as a microphone.
  • For YouTube, subscriptions, and update checks: an internet connection. Local playback works without internet.

Installation and First Launch

Download a file from the releases page: https://github.com/kamalyaser31/simple-player/releases. Each release has two files, named SimpleAudioPlayer-v2.0.0.exe and SimpleAudioPlayer-v2.0.0.zip for version 2.0.0.

  • Installer (.exe): installs for your Windows user only, so it does not ask for administrator rights. The default folder is %LOCALAPPDATA%\Programs\Simple Audio Player. The setup offers a desktop icon, which is off by default.
  • Portable (.zip): extract the folder anywhere and run SimpleAudioPlayer.exe.

When the app starts, you hear "Welcome to Simple Audio Player". If the YouTube components are missing, you also see a question about them. It comes back at every start until the components are installed or you tick "Don't show this message again". The release files do not include yt-dlp.exe and deno.exe. The app downloads them into its own folder. The dialog is named "YouTube Components". Choose Yes to download them now, or No if you only play local files. You can download them later from Settings, YouTube page.

After the first launch, open one file and check that you hear it. Then press Ctrl+P to open Preferences and look at the General and Audio pages.

Quick Start

  1. Press Ctrl+O. A standard Windows file dialog opens. Choose an audio file and press Enter. Playback starts.
  2. Press Space to pause. Press it again to continue.
  3. Press Right to jump forward and Left to jump back. The default jump is 5 seconds.
  4. Press Up and Down to change the volume. You hear the new level.
  5. To play every file in a folder, press Ctrl+Shift+O and choose the folder. Press Tab or Page Down for the next file, and Shift+Tab or Page Up for the previous file.
  6. To search YouTube, press Ctrl+Y, type your words and press Enter. Choose a result and press Enter.
  7. Press F1 at any time in the main window to open this guide. Press Alt to reach the menu bar.

Main Window and Menus

The main window is small. It has five buttons: Previous, Rewind, Play (it changes to Pause while playing), Forward and Next. It also has a menu bar. Almost everything is done with shortcuts or from the menu bar.

Tab and Shift+Tab are shortcuts for Next and Previous track. They do not move focus between the buttons. Use the shortcuts, or use the menu bar.

Menu bar

The menus, in order:

  • File: Open File..., Open Link..., Open YouTube Link..., Search YouTube..., Favorite videos..., Latest subscription videos, YouTube subscriptions..., Open Folder..., Open Containing Folder, File properties..., Opened Files..., Close File, Close all files, Test speakers, Preferences..., Exit.
  • Edit: Rename..., Delete, Copy, Paste, Mark Current File, Mark All Files, Clear Marked Files.
  • Bookmarks: Add a new bookmark, Manage bookmarks, and a submenu Jump to bookmark with Bookmark 1 to Bookmark 10.
  • Actions for marked files: Copy to folder..., Move to folder..., Copy to clipboard, Delete.
  • Player: Play/Pause; submenu Speed (Increase Speed, Decrease Speed, Reset Speed); Previous, Next, First File, Go to file..., Last File; Shuffle; Repeat File; Enable silence removal filter; submenu A-B loop (Set A (loop start), Set B (loop end), Clear A-B loop); Rewind, Forward, Beginning, End, Go to time...; submenu Jump to Percentage; submenu Control the clicks movement value; Sound Cards...
  • Video options: Download..., Video description..., Copy video link.
  • Recording: Start recording, Pause (it becomes Resume while paused), Stop, Open recordings folder.
  • Help: User Guide, What's new, submenu Contact me (Email, Telegram, Visit website), submenu Updates (Check for app updates, Update YouTube components), About.

Menu items show their shortcut after the name, so your screen reader reads it. If you change a shortcut, the menu shows the new one.

Items that are disabled

  • Before you open a file, most items in File, Edit and Player are disabled.
  • The Bookmarks menu is enabled only for a local file. It is disabled for web links and YouTube.
  • The Video options menu is enabled only while a YouTube video is playing.
  • The Actions for marked files menu is enabled only when at least one file is marked.
  • Rename and Delete, and File properties, work only on local files.
  • Start recording is disabled while recording. Pause and Stop are disabled when you are not recording.

The Escape key

While you play a video that you chose from a YouTube results list, press Escape in the main window. Playback stops, and the results list opens again on the same item. This is the quick way back to a list. See The results window.

Spoken messages and verbosity

The app speaks short messages. The General setting "Verbosity" has two values. Beginner speaks full sentences, for example "Volume 100 percent" and "Elapsed time: ..." and also says "Play" and "Pause". Advanced speaks the short form, for example "100%", and does not say "Play" or "Pause". Press Ctrl+Shift+V to switch. You hear "Beginner mode" or "Advanced mode". The choice is written to the settings file only if "Save settings on close" is on (see Using the Preferences dialog).

Playing Files and Controlling Playback

Play and pause

Press Space or Enter. If a file has finished and you press it again, the file starts from the beginning. With no file open you hear "No file loaded."

Move inside a file

Left and Right move by the current movement value. The default is 5 seconds. Add keys to move further:

  • Ctrl+Left and Ctrl+Right move 2 times the movement value.
  • Ctrl+Shift+Left and Ctrl+Shift+Right move 4 times.
  • Shift+Left and Shift+Right move 8 times.
  • Home goes to the beginning. End goes to the end.

Change the movement value with Shift+1 to Shift+0. You hear the new value. The values are 1 second, 5 seconds, 1 minute, 5 minutes, 10 minutes, 20 minutes, 30 minutes, 40 minutes, 50 minutes and 60 minutes. Shift+- selects "Custom value", which you set in Audio settings (default 5 seconds). The menu Player > Control the clicks movement value has the same choices.

Jump to a place

  • Ctrl+1 to Ctrl+9 jump to 10% to 90% of the file. Ctrl+0 jumps to the end. You hear the percentage.
  • Ctrl+Shift+1 to Ctrl+Shift+9 jump to 15% to 95%. Ctrl+Shift+0 jumps to the end.
  • Ctrl+Shift+G opens "Go to time". Use the spin boxes Hours, Minutes and Seconds, then choose OK. The Hours box shows only for files of one hour or more. The Minutes box shows only for files of one minute or more. A time after the end of the file is refused.

Ask for information

Single keys speak a fact. They need a loaded file.

  • E elapsed time, R remaining time, T total time, P percent played.
  • V volume, S speed.
  • F file information. Press once to hear the title or file name. Press twice quickly to hear the full path. Press three times quickly to copy the path to the clipboard. Each press must come within 0.3 seconds of the one before; a slower press starts again at the first step.

Volume

  • Up and Down change the volume by the Volume step (default 5).
  • Shift+Up sets the maximum, which is 1000%. Shift+Down sets 5%.
  • The volume runs from 0 to 1000. Above 100 the sound is amplified, so loud values can distort. The default is 100.

Speed

  • Ctrl+Up and Ctrl+Down change the speed by the Speed step (default 0.1). The range is 0.5 to 4.0.
  • Alt+Y sets 1.0 again.
  • You hear the speed, for example "1.1x".

Next and previous file

Tab or Page Down plays the next file. Shift+Tab or Page Up plays the previous file. Ctrl+Home goes to the first file and Ctrl+End to the last file. Ctrl+G asks for a file number, for example "Enter file number (1-12)". It needs at least two files. If you turn on "Speak file name when navigating (Previous/Next)", the app says the file name each time you use Next or Previous.

Shuffle, repeat and what happens at the end

  • Ctrl+Z turns Shuffle on or off. You hear "Shuffle on" or "Shuffle off". Shuffle is not available for YouTube; you hear "Shuffle is disabled for YouTube streams."
  • Ctrl+R turns Repeat File on or off. You hear "Repeat on" or "Repeat off".
  • At the end of a file the app does what the Audio setting "What happens after a file ends?" says: advance to the next file (default), loop the file, or do nothing.
  • "Wrap to top for multiple files" makes Next at the last file go to the first file, and Previous at the first file go to the last.

Repeat a part of a file (A-B loop)

  1. Go to the start of the part and press [. You hear "Start selection:" and the time.
  2. Go to the end of the part and press ]. You hear "End selection:" and the time. The part plays and repeats. If B is not after A, you hear "End selection must be after start."
  3. While the loop is active, the Left and Right keys stay inside the loop. Home goes to point A and End goes to point B.
  4. Press Backspace to clear the loop. Playback continues from point B.

The loop is cleared when you change to another file.

Files, Folders and the File List

Open files

  • Ctrl+O opens a file. The dialog lists "Audio Files" first. You can switch to "All Files".
  • Ctrl+Shift+O opens a folder. All files in it with a supported audio extension (listed below) are loaded. Subfolders are not included. If there are none, you hear "No audio files found in that folder."
  • Ctrl+L opens a link to a web stream. The link must start with http or https.
  • Ctrl+V opens what is on the clipboard: a file, a folder, a web link, or a YouTube link.

Supported file types for folders and for the file dialog: .aac .aiff .alac .flac .m4a .mp3 .mp4 .ogg .opus .wav .wma. The file dialog also offers "All Files". The app registers more video types with Windows Explorer, listed under Other Tools.

What happens when you open one file

The General setting "What would you like to open with files?" decides this. It applies to Ctrl+O, to Ctrl+V with a file, and to files opened from Explorer.

  • Open the file only (default): only that file.
  • Open the file and the main folder files: that file and the other files in its folder.
  • Open the file with the main and subfolder files: that file and the files in its folder and all subfolders. A progress window with Cancel shows while the app scans.

Both folder choices load only files with a supported audio extension (see the list above). If the file you open has another extension, for example a video type from "All Files", it is added to the list in its name order, and playback starts with it.

Open files from Windows Explorer

Use "Register file extensions" in General settings so that Windows can open files with this player. Then double-click a file, or press Enter on it in Explorer. The context menu also gets "Play with Simple Audio Player". Windows may still ask you to confirm the default app in its own Default apps settings. If the player is already running, the file opens in the running window. If you select several files in Explorer and open them together with "Open the file only", they open as one list. The setting "Switch to the player when opening a file from Explorer" brings the player window to the front and gives it focus. It is off by default, so focus stays in Explorer.

The Opened Files list

Press F2. A list of all loaded files opens, with the current file selected. Press Enter or choose "Jump to selected" to play that file. Choose "Cancel" to close. The "Playlist info" button shows the number of files, total size, total duration, elapsed time and remaining time.

Close files

  • Ctrl+W removes the current file from the list. This does not delete the file on disk.
  • Ctrl+Shift+W removes all files from the list.

Rename, delete, copy

These work on the current local file.

  • Shift+F2 asks for a new name.
  • Shift+Delete asks "Delete 'name'?" and then deletes the file. The file is deleted for good. It does not go to the Recycle Bin.
  • Ctrl+Shift+C copies the file to the Windows clipboard, so you can paste it in Explorer.
  • Ctrl+F opens the file's folder in Explorer.
  • Alt+Enter opens the Windows Properties window of the file.

Mark files and act on many files

  1. Mark files: Ctrl+K marks or unmarks the current file. Ctrl+A marks or unmarks all files. Ctrl+Shift+K clears all marks. K says how many files are marked.
  2. Open the menu "Actions for marked files". Choose one of: "Copy to folder...", "Move to folder...", "Copy to clipboard", or "Delete". These items have no default shortcut.
  3. Copy and Move ask for a folder and show progress with Cancel. If a file with the same name exists, the new file gets a number, such as "song (1).mp3". Moved files leave the list.
  4. Delete asks "Delete N marked files?". It deletes the files for good, with no Recycle Bin.

Remember positions

Two settings sound alike but do different things.

  • General: "Remember last file position". When the app starts without a file to open, it reopens the last file at the time where you stopped.
  • Audio: "Save current position for each file". The app stores the position of the current file when you press Next or Previous, and when you close the app. When you later move to that file with Next, Previous, Go to file, First File, Last File or Opened Files, it continues from the stored position. Opening a file with Ctrl+O does not restore it. The positions are stored in positions.json.

Bookmarks

A bookmark is a named place in a local file. Bookmarks do not work for web links or YouTube.

  • Shift+M adds a bookmark at the current time. A box asks "Enter bookmark name". The suggested name is "Bookmark" and the time. Type a name and press Enter. A message confirms it.
  • Ctrl+Shift+M opens "Manage bookmarks" for the current file. If there are none, a message says "No bookmarks found for the current file." The list has the columns Name and Position. Buttons: Jump, Edit, Delete, Close. Enter on a bookmark jumps to it. Edit asks for a new name. Delete asks to confirm.
  • Alt+1 to Alt+9 and Alt+0 jump to bookmark 1 to 10. If the slot is empty, you hear "No bookmark in slot N." The same items are in Bookmarks > Jump to bookmark.

Slot numbers follow the time order inside the file, not the order you created them. Slot 1 is the bookmark nearest to the start of the file. If you add a bookmark before the others, the slot numbers shift.

Bookmarks are stored in bookmarks.json. See Data, Backup and Restore.

YouTube: Opening Links, Searching, the Results Window, Downloading

YouTube features need the components yt-dlp and Deno, and an internet connection. If they are missing, you hear or see a message that tells you to install or repair them in Settings. See Settings, YouTube page.

Open a YouTube link

  1. Press Ctrl+Shift+Y. A box says "Enter a YouTube video or playlist link."
  2. Paste the link and press Enter.
  • A video link plays at once.
  • A playlist link opens the results window with the playlist videos.
  • A link with both a video and a playlist follows the YouTube setting "Video+playlist link behavior": ask every time (a box offers "Play the video", "Open the playlist" and "Cancel"), always play the video, or always open the playlist.
  • Channel links are refused here ("Channel links are not supported here."). To follow a channel, use YouTube Subscriptions.

If a YouTube link is on the clipboard, Ctrl+V opens it the same way.

Search YouTube

  1. Press Ctrl+Y. A box says "Enter search text."
  2. Type your words and press Enter. A window named "Searching YouTube" shows while the app works. Choose Cancel to stop.
  3. The results window opens.

The search uses the language code and region code from the YouTube settings (defaults "en" and "US"). If a code is not valid, the app uses the default. When you reach the last result, more results load, and you hear "Loading more videos...".

The results window

The window is named "Videos". Above the list a label tells the kind: "Search results", "Playlist videos", "Latest videos" or "Channel videos". The first video is selected. Use Up and Down to move. The buttons are Play, Download and Close.

After you play a result

  • Press Escape in the main window to stop and return to the results list at the same item.
  • Press Tab or Page Down for the next item in the list, and Shift+Tab or Page Up for the previous one. If the next video is not ready, you hear "Loading next video...".
  • At the end of a video the app moves to the next one on its own only for a playlist, and only when "What happens after a file ends?" is set to "Advance to the next file" and Repeat File is off. Search results, the latest-videos list and a channel list stop at the end of each video.
  • The app prepares the next videos in the background. The YouTube setting "Prefetch count" says how many. If a stream link has expired, the app tries to reload it once.

Audio only or video

By default the app plays YouTube as audio only. The YouTube setting "Play videos as audio only" controls this. When you turn it off, the setting "Video quality" (Low, Medium or Best) applies.

Download audio

  1. While a YouTube video plays, press Ctrl+D. Or choose Video options > Download.... Or use the Download button in the results window.
  2. A dialog named "Select download folder" opens. Choose a folder.
  3. A window named "Downloading audio" shows total size, downloaded size and percentage. Choose Cancel to stop.
  4. When it finishes you hear "Download completed."

The file is saved as M4A audio, named after the video title. Only the single video is downloaded, never a whole playlist. A download that makes no progress for 60 seconds stops with an error.

Description and link of the playing video

  • Alt+D opens the description in a read-only box named "Video description". Choose Close or press Escape to leave it.
  • Video options > Copy video link copies the link. This item has no default shortcut.

Update the YouTube components

Choose Help > Updates > Update YouTube components. This updates yt-dlp to the newest version of the channel you chose in Settings (Stable, Nightly or Master). You hear the result: updated, or already up to date. To install missing components, use the button "Download YouTube components" in Settings, YouTube. If you turn on "Check for yt-dlp updates on startup", the app asks at startup whether to update when a newer version exists.

YouTube Subscriptions

You can follow YouTube channels and save playlists. You need no Google account and no sign-in. The list is stored only on your computer, in subscriptions.json. The app reads each channel's public YouTube feed.

Subscribe

  • From a results list: select a video and press Ctrl+S. The app subscribes to that video's channel. You hear "Subscribed to" and the name, or "Already subscribed to" and the name.
  • By link: press Ctrl+Shift+U, choose "Add by link...", and paste a channel link or a playlist link. A channel link can have the forms /channel/..., @name, /c/... or /user/.... A playlist link has list= in it.

Latest videos of your channels

Press Ctrl+U (File > Latest subscription videos).

  • A window named "Loading subscriptions" shows while the app reads the feeds. Choose Cancel to stop.
  • The results window opens with the label "Latest videos". It shows up to 50 of the newest videos from all your followed channels, newest first. Shorts are left out. Playlists are not included.
  • Each line reads: video title, channel name, age. The age is "today", "yesterday", then days, months or years, for example "3 days ago", "1 month ago" or "2 years ago".
  • If some channels cannot be loaded, you hear how many. The others still show.
  • If you follow no channel, you hear "You do not follow any channel yet." and the subscriptions window opens. Saved playlists do not count here.
  • This list does not move on to the next video by itself when a video ends. Use Tab or Page Down.

Manage subscriptions

Press Ctrl+Shift+U (File > YouTube subscriptions...). The window is named "YouTube subscriptions". The list is labelled "Subscriptions". Each line reads "name - channel" or "name - playlist". The newest subscription is first.

Controls in the subscriptions window
ControlWhat it does

Channel lists also do not move on by themselves at the end of a video. If your internet is off, you hear or see "Could not reach YouTube. Check your internet connection." Playing a video still needs the YouTube components.

Favorites

"Favorite videos" is a list of links you open often. Press Ctrl+Shift+F or choose File > Favorite videos.... The list has the columns Name, Type and Link. The buttons are Add..., Edit..., Remove... and Close. Press Enter on an item to open it.

The types are:

  • Video: a YouTube video link. It plays that video.
  • Playlist: a YouTube playlist link. It opens as a playlist.
  • Combined link: a YouTube link with both a video and a playlist. It follows your YouTube setting "Video+playlist link behavior".
  • Generic stream: any http or https link. It plays as a normal stream, without YouTube tools.

Add and Edit ask for a Name, a Type and a Link. If something is wrong, a message tells you, for example "Name is required." or "Playlist favorites require a YouTube playlist link." Remove asks to confirm. Favorites are stored in favorites.json.

Recording

Recording captures from your default Windows input device, for example a microphone. It does not record what the player plays. The sample rate is fixed at 44100 Hz.

  • F9 starts. You hear a high beep (880 Hz) first.
  • F7 pauses and you hear "paused". Press F7 again to resume, after a high beep.
  • F8 stops, with a lower beep (440 Hz).
  • The same commands are in the Recording menu. Recording > Open recordings folder opens the folder in Explorer. It has no default shortcut.
  • The global shortcuts Alt+Win+F9, Alt+Win+F7 and Alt+Win+F8 do the same from any program.

Files are named recording_, the date and time, and the extension, for example recording_20261113_093000.wav. The format, channels, bitrate and folder come from Settings, Recording page. If a recording is still running when you close the app, it is stopped. If recording cannot start, a message box named "Recording" shows the reason.

Other Tools

Silence removal

Press Ctrl+M to turn the silence removal filter on or off. You hear "Silence removal on" or "Silence removal off". The choice is saved. The filter cuts silent parts out of playback, which is useful for speech. Tune it in Settings, Silence removal page.

Sound cards

Press Ctrl+Shift+A. A dialog named "Sound Cards" has a drop-down box "Select sound card". Choose a device and press OK. You hear "Sound card set." The choice is saved.

Test speakers

Press Ctrl+Shift+T. The app plays a test sound and says "Testing speakers."

Audio processing

Audio settings has two filters: "Enable dynamic normalize and limiter" (on by default) and "Play audio as Mono" (off by default).

Windows media keys

The app tells Windows what it plays. The media keys of your keyboard and the Windows media controls work: Play and Pause, Next, Previous, Fast forward (same as Seek Forward) and Rewind (same as Seek Backward).

Global shortcuts

A set of shortcuts works while another program has focus. See Global shortcuts.

File types registered with Explorer

"Register file extensions" in General settings registers the audio types listed in Files, Folders and the File List and these video types: .3gp .avi .flv .m2ts .m4v .mkv .mov .mpeg .mp4 .mpg .ts .webm .wmv. "Unregister file extensions" removes what the app registered. It does not delete any media file. The installer also registers these types.

Updates of the app

  • Help > Updates > Check for app updates looks for a newer version. If you have the newest, you hear "You are using the latest version."
  • If there is a newer version, a dialog named "Application update" shows the version and "What's new". Choose Update to download it, or Later. After the download the app closes and the updater installs the new version. An installed copy downloads the installer. A portable copy downloads the zip.
  • The General setting "Check for app updates on startup" (on by default) does this check when the app starts.

Help menu

F1 or Help > User Guide opens this guide in your browser, in your app language if it exists. "What's new" opens the list of changes. "About" shows the version and the developer. The Contact me submenu has Email, Telegram and Visit website.

Settings

Using the Preferences dialog

Press Ctrl+P or choose File > Preferences.... The dialog is named "Preferences". On the left is a tree of pages. Use Up and Down to choose a page. The page appears on the right. Use Tab to go into the page. The pages, in order: General, Backup and restore, Audio, Silence removal, Recording, YouTube, Keyboard Shortcuts, Global shortcuts.

  • Choose OK to save the changes of all pages. If a value is wrong, a message tells you and the dialog stays open.
  • Choose Cancel to drop the changes.
  • Press F1 on a control to hear short help for it. On the tree, F1 explains the tree.
  • The buttons on the Backup and restore page act at once. They do not wait for OK.

"Save settings on close" in General matters here. If you turn it off, the app saves only that one choice. Changes you make with OK, with Ctrl+Shift+V, with the movement value keys, or with Ctrl+M then last only until you close the app. Bookmarks, favorites and subscriptions are saved at once, whatever this setting says. A file position is saved at once when you press Next or Previous, but the position saved when you close the app needs this setting on.

Keyboard Shortcuts and Global shortcuts pages

Configuring Shortcuts and Global Shortcuts

Local shortcuts

These work when the player window has focus.

  1. Press Ctrl+P and choose the page "Keyboard Shortcuts".
  2. Choose an action in the list. The list has the columns Action, Primary Shortcut and Secondary Shortcut.
  3. Activate "Edit Primary Shortcut". A small dialog named "Set Shortcut" says "Press the desired shortcut. Escape cancels."
  4. Press the new keys. The dialog closes and the list shows the new shortcut.
  5. Choose OK in Preferences to save.
  • Only "Play/Pause", "Next Track" and "Previous Track" have a secondary shortcut. Use "Edit Secondary Shortcut" for it.
  • Actions without a default shortcut can get one in the same way, such as "Copy Video Link" or "Open Recordings Folder".
  • If the keys already belong to another action, a message named "Shortcut Conflict" says "That shortcut is already assigned to another action." and the old one stays.
  • "Reset to Defaults" asks "Reset all shortcuts to defaults?". It is enabled only when you changed something.
  • Local shortcuts cannot use the Windows key: the main window ignores any local shortcut that includes it. Use Global shortcuts for those keys.
  • The action names in this list are in English.

Global shortcuts

Global shortcuts work while the player runs in the background, even when another program has focus. They are on the page "Global shortcuts" of Preferences. The dialog there is named "Set Global Shortcut", and it says "Press the desired global shortcut. Escape cancels." This page has only primary shortcuts, and no secondary column.

Data, Backup and Restore

The app keeps its data in one folder: %APPDATA%\Simple Audio Player. To open it, use the button "Open user settings folder" in Preferences, Backup and restore.

Back up

  1. Press Ctrl+P and choose the page "Backup and restore".
  2. Use "Export settings" and "Export bookmarks". Choose where to save each file.
  3. Use "Export favorites and subscriptions" for those two lists. File positions have no button: copy positions.json by hand from the settings folder.

Restore on a new computer

  1. Install the app and start it once.
  2. In Preferences, Backup and restore, use "Import settings", "Import bookmarks" and "Import favorites and subscriptions", and choose your saved files.
  3. To restore favorites, subscriptions or positions, close the app and copy the saved files into the settings folder.
  4. If you change the language, restart the app.

Start again with default settings

Use "Reset settings" on the Backup and restore page.

Troubleshooting

I hear no sound

  1. Press Ctrl+Shift+T to play the test sound.
  2. If you hear nothing, press Ctrl+Shift+A and choose another sound card.
  3. Press V to check the volume. Press S to check the speed.

Menu items are disabled

Most items need a loaded file. Bookmarks need a local file, not a link. Video options need a YouTube video. Actions for marked files need a marked file.

Tab does not move between the buttons

This is normal. Tab plays the next file. Use the shortcuts or the menu bar.

YouTube does not work

  1. Check your internet connection.
  2. If a message says that components are missing, open Preferences, YouTube, and choose "Download YouTube components".
  3. If the components exist but a video fails, choose Help > Updates > Update YouTube components.
  4. If search finds nothing useful, check "Search language code" and "Search region code".

The next YouTube video does not start by itself

Only playlists move on automatically. Search results, the latest-videos list and channel lists do not. Press Tab or Page Down. A playlist also needs "What happens after a file ends?" set to "Advance to the next file" and Repeat File off.

My settings were not kept

Turn on "Save settings on close" in General.

A file does not continue where I left it

Turn on "Save current position for each file" in Audio to continue per file when you move between files in the list. Turn on "Remember last file position" in General to reopen the last file when the app starts.

I deleted a file by mistake

Shift+Delete and the marked-files "Delete" remove the file for good. They do not use the Recycle Bin. Restore it from your own backup.

A global shortcut does nothing

Another program may use the same keys. Choose another combination in Preferences, Global shortcuts.

Recording does not start

A message named "Recording" shows the reason. Check that Windows has a default input device and that the recordings folder can be written to.

Files do not open from Explorer

Use "Register file extensions" in General. Then, if Windows still opens another app, choose Simple Audio Player in the Windows Default apps settings.
